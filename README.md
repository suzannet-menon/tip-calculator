# Tip Calculator & Bill Splitter

A responsive frontend web application that calculates tips and splits bills between multiple people in real time.

## Features

- Currency selection
- Bill amount input
- Preset tip percentage buttons
- Custom tip percentage input
- Live calculation updates
- Per-person bill splitting
- Reset functionality
- Responsive design for desktop and mobile

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

---

## Installation & Running Locally

No additional installations or dependencies are required.

### Steps

1. Clone the repository

```bash
git clone https://github.com/suzannet-menon/tip-calculator.git
```

2. Navigate into the project folder

```bash
cd tip-calculator
```

3. Open `index.html` in your browser
